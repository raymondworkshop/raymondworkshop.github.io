Title: #self

跟职场技能技巧关系不大， 更多的是对一个社会的深层的理解

职场文化 是社会文化的延伸

美国是个开放社会，就是一个底层自治的社会 - 自己想实现的事情 - 每个人都具备领导力 - 无中生有地创造 - 跟非常不同的人打交道

非常firm的提出自己的观点， 但是又不对别人形成这种攻击性的 - 在东亚文化里是不鼓励的 - 东亚教育里是有很多恐惧的，说错话是有代价的

- “去人格化“ 与 ”以利益/事实为锚“
     +   锚定共同目标， 提出客观约束 +  清晰亮明底线 + 抛出建设性出路
     +   ”我们都希望这个项目能顺利按时交付。 但从目前的承载能力来看， 这个排期我们无法按原计划执行。  为了确保不延期， 我们需要把重点放在方案a上， 你看这样调整是否可行？“

看到自己的内心，自己的情绪是怎么来的，然后理解自己最深的恐惧是哪里来的 也要了解外面的社会

向外 - 认识世界 - 家庭 - 社会关系 - 制度 - 历史 - 人类与万物

向内 - 认识自己 - 身体 - 情绪 - 能量 - 智慧 - being
