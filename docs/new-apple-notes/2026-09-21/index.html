ON（Optimum Nutrition）金牌乳清蛋白粉（Gold Standard 100% Whey）双倍浓郁巧克力味

每個動作做 3–4 組。因為 5 kg 重量固定，如果每組做 12 下覺得太輕鬆，可以提高到 15–20 下，直到肌肉感覺酸痛發熱為止。

動作 1：啞鈴高腳杯深蹲（Dumbbell Goblet Squat） 怎麼做： 雙手捧著一隻 5kg 啞鈴在胸前，像坐椅子一樣蹲下再站起。 目標： 刺激大腿。如果覺得輕，可以兩手各拿一隻 5kg（共 10kg）放在雙肩上蹲。 動作 2：地板啞鈴臥推（Floor Press） 怎麼做： 躺在瑜伽墊上，雙腳屈膝。雙手各拿一隻 5kg 啞鈴，手臂垂直向上推起，手肘下落到輕觸地板即可。 目標： 在沒有椅子的情況下，這能安全地鍛鍊胸肌。 動作 3：俯身雙臂啞鈴划船（Bent Over Row） 怎麼做： 雙腳微屈，上半身向前傾斜約 45 度並保持背部挺直。雙手各拿 5kg 啞鈴，將啞鈴往肚臍方向拉起。 目標： 鍛鍊背部，讓上半身視覺上變寬。 動作 4：跪姿/站姿啞鈴推舉（Shoulder Press） 怎麼做： 挺胸收腹，雙手持啞鈴由肩膀高度垂直向上推過頭頂。 目標： 鍛鍊肩膀，打造穿衣好看的衣架子身材。

核心節奏：練完這 4 個動作後，30 分鐘內立刻泡一杯 1 湯匙雙倍巧克力 ＋ 300-350ml 全脂牛奶 喝下去，這就是肌肉生長最強大的燃料！

Title: #self

被審視的感覺 - 當別人指出你的問題時， 理性會把這當成一次“考核”或“攻擊”。 覺得自己的“漏洞” 被暴露在陽光之下， 這種審視感 會引發身體的羞恥或尷尬

-   結果導向和工具化視角： 理性覺得反饋的價值在於“能不能幫忙解決問題”；
     如果對方只“說”不“做”， 理性就會判定對方的言論無效，甚至帶有居高臨下的優越感，從而產生排斥

區分 “提供視角” VS “提供解法” - 有兩種禮物： 一種是“工具” （幫你幹活）， 一種是 “視角” （讓你看到盲點） + 把“要求對方給解法” 轉化爲 “謝謝讓我多看到了一種可能性”

- 把“審視” 翻譯成 “一面鏡子”
     +  他只是說出了他眼中看到的我的樣子
          至於要不要調整，主動權在我手裡

-  把對方的“說” 看作一種 “情緒或需求的表達”
     +   去看他話語背後的狀態時，內心的防禦就會放下大半
           他此刻為什麼要在意這件事？  他急於表達的背後，是對團隊整體的焦慮，還是他也需要一種安全感

Title: #self

用腦太多, 而不是用心 - 太重視邏輯， 太重視整體， 太工具化， 太交易化 - 習慣了用腦保護自己的人， 是覺得 邏輯和理性更安全

從“頭腦” 到 “心靈” - 看見具體的個體 <- 從 關注整體/目標 + 把注意力從“整個團隊” 落到一個具體的人身上 + 每次交流時， 在心裏對自己說 “此刻坐在我面前的是一個有著喜怒哀樂的活生生的人，不是一個”合作對象“ - 關注對方的微表情，情緒狀態， 而不只是他說的話是否符合邏輯

- 共情與陪伴 <- 解決問題/給建議
    +   先接納情緒，再處理事情 
          -  對方要的可能不是答案，而是理解

          -  開啟身體雷達， 試著用身體去“接受” 對方的整體氛圍，而不是去對他的話語對錯進行判別

          -  練習去聽對方話語底層的心裏需求 （渴望被理解，渴望安全感，感到委屈——， 而不是 去挑錯或找解決方案

          - 像“鏡子”一樣去映射，而不是做“法官”去評判
               +   試著用情緒去核對對方的感受，而不是給建議
               +   “聽你這麼說，我感覺你現在特別無助/委屈，對嘛？”

               + “這會兒心裏是在想些什麼？”
               +  “你心裡是什麼感覺？”

    +    “聽到你這麼說，我能感受到你現在挺不容易的...”
          - “這時候，你需要我給妳一個擁抱，還是只想找個人挺你倒倒苦水“

-  無條件的享受當下 <- 價值交易/功利化
    +    覺察自己內心深處的“價值計算器”； 問自己 “我是因為這個人有用，有趣，能幫到我才靠近他， 還是純粹因為和他在一起感到開心放鬆？“

    +     允許這段時間是“浪費”的， 只享受陪伴本身的溫度

-  身體感知 <- 從“腦力控制”
    +     把注意力從 思考 下沉到 身體 （感受）。 很多時候， 當我們過度用腦時，身體是緊繃的

    +      在準備開口或回應時， 先做一個呼吸，感受一下自己的腳掌是否踩在地面上
            +    問問自己： “此刻我的心裏是什麼感覺？ 我是溫暖的，防備的，還是給予表現的？”
            +    借由呼吸找回身體的直覺
