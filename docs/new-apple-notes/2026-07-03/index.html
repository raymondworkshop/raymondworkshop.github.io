情感捕捉 与 情感接纳

- 体察她的情绪 意味着 “放下你预设的剧本， 去读取她当下的震动”

-  情绪的 “镜像反馈” (Mirroring)

-   关键在于反馈她的情绪， 而不是她的事实

体察情绪 + 镜像反馈

- 观察 -   从“关注事实“ 切换到 “关注感受”
    +   练习：  在对话中，心理快速扫描：  “这句话包含什么情绪？” 
    +   情绪词清单：  疲惫、焦虑、兴奋、失望、被误解、被忽略、有压力、兴奋、无奈

    +  你需要练习的思维：  对方现在感到  …

  • 实施 - 镜像反馈 + 确认对方的感觉 + 用你的话复述出来

    +   我感觉到了 “情绪标签” + 因为“对方提到的原因”
      - “看来这件事让你觉得 【情绪】， 换做是我可能也会这样“
      -  ”我感觉到你现在对这件事情有些 【情绪】， 是这样吗？”

  • 进阶 - 通过 “镜像反馈” 建立深度连接 + 尝试在反馈中加入一点自己的 “情绪共鸣”， 而不只是复述 

    +   暂停：  在回应前， 停顿1-2秒， 展现你真的在思考

+    承认对方的逻辑 (Validation):  “我完全理解为什么你会这么想…”, “这确实很让人心烦…”

+   不给建议，直到被要求：  只有当对方说 “我该怎么办？”时， 才开始你的技术或策略输出
