   +    两侧 - 消融白发
          - 两鬓白发比较多，耳周和鬓角推到接近皮肤的长度，把两鬓白发的边界完全过渡掉。

          -  顶部保留3-4cm长度， 做豐富的層次打薄和紋理剪裁
          -   平时我要往后、往侧上方吹蓬松，有层次才不会贴头皮，发丝也好看
          -  顶部保持 $3-4 cm 的长度，通过吹风机顺着头发生长方向往后、往侧上方吹高，露出额头。

   +    细节
          - 发际线和鬓角边缘帮我修一条干净的轮廓线，顺便帮我把眉毛周围的杂毛修一下

- 一次全剪， 一次只修两侧

为什么别人“收不到”你 - “解决问题思维” 掩盖了 “情感连接”

- 情感表达的 “内敛”

-  防御机制
    +  过度理智时一种自我保护

如何让别人“接受”到你的爱？ - 先“接住情绪”， 再“处理事情’ + 先情绪共振 + 爱的连接回答 “听起来你最近真的承受好多压力，换作谁都会委屈”

 - 把客观事实，加上一句主观的，关于“我”对“你” 的 情感连接词
     +   理性表达： “明天气温降到15度，记得穿外套”

     +   带温度表达： “明天降温，我特意看了一下， 你出门记得加件厚衣服，别感冒了”

 -  允许自己展现“不完美”和“脆弱”
     +  真正的亲密关系 往往建立在 “脆弱的共享‘上

     + 不需要总是表现得无所不能，绝对正确

     +   偶尔在信任的人面前承认： ”其实我今天有点没把握“， ”这件事我也不知道，有你在身边陪我感觉好多了“

     +   展示脆弱，是向对方发出最高级别的信任邀请，也是最强效的爱的表达
