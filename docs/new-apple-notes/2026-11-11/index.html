Title: #management

Build family culture - safety, belonging, trust, and shared vulnerability

- trust: 让人感觉 “我可以依靠你”
- belonging:  让人感觉 “这里有我的位置”
- shared vulnerability:  前两者的粘合剂

respect
- 将对方视为一个独立的个体， 认可并接纳彼此的差异，边界和选择， 即使在不认同对方的时，依然保持敬意

- 尊重界限， 情绪和想法

Collaboration - 我们 vs 问题 （一起向办法解决问题）

- win-win: 面对分歧时，愿意沟通，找到双方舒服的平衡点

shared vulnerability 互相袒露脆弱 - 它告诉大家： 在这里， 我们可以做真实的自己，不必完美，依然被爱与尊重

- leader/主导者 作表率， 能迅速拉近距离

-  建立 “心理安全区”
    +   当家人或朋友向你倾诉他们的不完美或失败时， 不评价，不急于讲大道理，不嘲笑，
    用倾听和接纳回应他们的坦诚

 -   分清 “展现脆弱” 与 “情绪绑架” 
    +    展现脆弱是未来 “建立连接”， 而 情绪绑架是为了 “索取控制” 或 “甩包袱”
           -  真正的脆弱，是带着勇气展示伤口， 但并不要求别人替你插血

    +  先预判并询问对方的 “心理空间”
         -  先问对方 “我最近有些困惑/心里有些难过，你现在有精力听我聊聊吗？”

    +   使用”I” statement, 少用 “You” 指责  
         -   多说 “我感到...”

    +    明确你的需求
         -  告诉对方你希望他们做什么

Life is short, so love your life, be happy and keep smiling. Expectations always hurt.
