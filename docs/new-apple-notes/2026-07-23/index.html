     - 展現紳士風度與擔當：  多照顧同行的長者。 如果需要幫忙看路，主動去做，用行動說話

     -  展示 情緒穩定：  表現最淡定。 不抱怨，不發牢騷， 甚至還能適時打圓場

     -  建立自然的連結： 找機會跟amos聊一些 感興趣的話題

-  尊重的導師關係
     -  單獨約他， 想聽聽對方的眼光和指教  
          +  專注於 事業和請教： 聊你的項目和構思， 聽他的商業見解
          + 「Amos 哥，上次聽您說願意幫忙，我心裡真的很感激。我最近在自己搞一些軟件開發和知識管理的嘗試（也就是你目前在做的項目 MVP），雖然現在還在很早期的階段、甚至還很粗糙，但我知道您在商場見過大風大浪，特別想拿這些粗淺的想法來聽聽您的見解，看我有沒有走彎路。這週或下週您得閒的話，我請您飲杯茶？」

     -  靠譜的成年人： 一個敢於拿著早期項目向資深前輩請教，不怕露怯，願意虛心學習，
     在長輩眼中的分數會遠高於只會獻殷勤、討好女兒的人
           +  不要怕露怯： 誰都是從早期開始的，真誠永遠是最好的必殺技。

          +  建立連結

    -  不要以“拉投資”的名義
          +  你的洞察力： 你為什麼要做這個項目？ 你看到了什麼痛點？

如何展現 可靠 與 同理心

可靠 - 預期管理 與 言行一致

-   講得出，做得到
     +   如果真的無法作答， 提早溝通並提出 替代方案

  • 危機時的 “錨點” + 穩住陣腳， “別擔心，看看我們現在可以怎麼解決”

  • 嚴守秘密與界線

展現 “同理心” - 聽懂對方的需求 - 聆聽與理解， 站在對方視角感受世界

-  先接納情緒，再處理事情
       +  先同理對方感受

-  深度聆聽
       +  點頭或覆述重點來回應  “所以你的意思是 … 對嗎？”

-  記住生活中的微小細節

卖东西给朋友 我自己如果有提成或 赚的很多 自己会有些不好意思， 觉得在转朋友的钱

商业与人情平衡思维， 而不是 樸素的 情感思維 - 把規則提前說清楚，擺在明面 + “我平時對這方面比較熟，也有渠道幫你對接。 如果合適，你決定辦的話， 那邊機構會有轉介佣金給我。 你看需不需要我幫你安排？

 - 先讲规矩，后谈交情

潛意識 把 “賺錢” = “剝削” - 賺朋友的錢 是在 “利用朋友” 或 ”占朋友便宜”

 -  擔心友誼變質：  害怕彼此關係不再純粹，如果未來出現問題或朋友覺得不划算，會影響兩人情感

如何處理“熟人商業” - 保持專業和透明

      +  ”靠專業服務費”  同 “靠資源割韭菜” 
            -   區別  ” 賦能”  VS  ” 利用” 
            -  如果提供的東西 是對方本來就剛需， 且市面上價格就是如此。
              你賺的是明面上的“服務報酬”， 而不是剝削

            -  如果明知這個產品不適合對方，或利用對方的盲目信任， 榨取高價 - 這就是透支

            -  提供超額價值： 讓金錢流動 變成雙向賦能

     + 在香港本地， 把“佣金/提成” 轉化爲 “明面上的服務與回饋”
            -   香港人做事講究清清楚楚，明碼標價
            -   公開透明並主動讓利：  選擇把一部分傭金/回扣 直接讓給對方

-  把重點放在 “價值” 而非 “價格”上
     +   你其實是在 “幫朋友解決問題”， 而不是 在 “賺朋友的錢”
     +  ”我幫他解決了什麼風險”，  而不是 ”我從他身上拿走了多少”

  • 設立隔離區 + 轉接給專業的朋友

  • 健康的长期关系一定是互惠且舒适的 + 只要你問心無愧， 沒有欺瞞， 提供的是真正有價值的服務，收穫合理的報酬是一件光明正大的事

香港 的 關係與商業 - 分層處理

-  關係越近，規則越要拿到台面上
     +  明確權責： 誰出資，誰出力，賺了怎麼分，虧了怎麼擔，出現糾紛怎麼解決

- 普通親戚，普通朋友
    +     大方談佣金， 但主動讓利 
    +    “我肯定幫你拿最好的方案。這裡面公司有合規的轉介費。 我拿一部分直接給你做個回贈”

  • 摯友

    • 把商業和友情徹底隔離

    • 做中間引薦人， 但明確聲明自己不拿任何一分錢提成

    • 放棄眼前的佣金， 買回來的是 放心交底的真摯友情
