给人温暖

让肢体语言先于理性开口 - 严肃和僵硬往往源于身体处于防御状态 - 微微放松肩膀、将紧咬的下颌松开、让眼神带上一丝笑意。 身体的松弛会直接传递给对方一种安全感，比任何理性的语言都管用

把“解决问题”切换成“接住情绪” - 温暖的替代方案： “听到你这么说，我能感觉到你当时挺委屈/挺不容易的……”

多用“自我暴露”来卸下防备 过于理性的人常常习惯藏起自己的脆弱和不确定。试着主动分享一些无伤大雅的小窘迫、小真实，或者你当时的真实感受。这种适度的“不完美”和坦诚，是拉近心理距离、产生人情味的催化剂。

Title: #info

当对方讲自己的story, view的时候， - 在香港， 表达往往偏高效， 直接且带有试探性

先通过肯定对方的情绪或存在来建立安全感（接住）， 然后再用你的好奇心或思考去开拓话题的边界（延展） - 先停顿，比如点头，眼神， 传递： 我听到了 - 接住 情绪或逻辑 - 承认对方有这样想的权力 + 轻量认可： “这个视角挺特别的 …” + 复述确认： “听得出来，你对这件事挺有感触的 …” + 情绪共振： “确实，现在大家对这个都挺头疼的…”

-  延展： 拋出好奇心 
    +  利用港人喜歡表達見解的特點，把話題往縱深處或輕鬆放下引
    +  追問契機： “是什麼讓你開始注意到這一點的？”
    +  類比延展： “這讓我想起我之前遇到過的一個情況，不知道你有沒有類似的感覺？”
    + 適度幽默/鬆弛： “你這麼一說，我得回去好好反思下我的消費觀”

- 回歸鬆弛，享受碰撞
    + 当对方看到你稳稳接住了她的话，并且有兴趣进一步探讨时，她的防御心也会自然卸下

善用“缓冲” - “这个角度挺有意思，我之前还真没从这方面想过 …“ - “你这么说倒提醒我，让我想一想 …”

把对方观点“抛回”给她 - 如果不确定对方是否在试探，最好 反问或复述来拓展话题 - “听起来你对这件事很有主见， 是谁什么契机让你有这种看法”？ - “你的意思是 .., 对吗？“

建立“保留意见”的表达习惯 - 如果当时没想好立场， 表达“需要沉淀” - “我目前对这个还没完全定论， 不过你的观点对我很有启发” - “这事信息量有些大，改天再给你聊”
