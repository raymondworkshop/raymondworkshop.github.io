展現“現實邏輯”： 用“博弈思維” 代替 “算計感” （交易思維） - 博弈思維： 战略协作与系统设计 + 塑造遊戲規則
+ 他人感知： 高度可預測， 有原則且 底線清晰
+ 重複博弈， 看重長期復利與無形的“聲譽資產” + 非零和博弈： 如何設計機制把蛋糕做大

- how
        +  以 “有條件的高價值給予” 開局
              -  “帶原諒機制的以牙還牙” 
              -  高姿態開局： 率先提供 無條件的高價值輸入， 傳遞出你資源充沛與誠意。
                  +   一旦對方單向榨取， 立即劃清界線或收回資源。 這是規則的執行
                  +   只要對方重新回到合作，立刻恢復合作

        +  設計 “機制對齊”
               -  設計激勵結構，使對方在完全出於自身理性利益做選擇時，其行為恰好最符合你的目標
               -  不要試圖改變對方的人格或道德， 分析對方的“收益矩陣”； 改變遊戲結構，讓厲害關係自然對齊

        +  用“預留讓利空間” 換取 “聲譽復利”
               - 在早期或次要環節 主動將一部分顯性利益留在桌上，相當於在對方或市場上建立“戰略應收款”

-  踐行  
       +   重構提問：  “通過這次互動，我在與對方建立一套什麼樣的長期規則？”  
       +    讓你的原則顯性化：   戰略型高手是及其容易被“預測”的，因為他們的原則清晰，前後一致

       +    展示 “高能力+低匱乏感”：  可以承受短期小虧，以鎖定長期超額收益
