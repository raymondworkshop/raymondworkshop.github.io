魅力學

三個感覺 - 他是對我友好的 - 我會尊重他我會欣賞他 - 互動時， 我會覺得自己是全場唯一一個被他看見的人

溫暖 + 力量 + 全心全意的存在感

溫暖： 沒有恐懼 沒有敵意的狀態 - 信任 - 善意：看到别人好的地方

力量 - 內在主權感 inner sovereignty - 情绪承载力 - 能够承载别人的情绪， 不确定性或压力或混乱 - 能够在别人坠落时，情绪上接住他 - 地心引力

全心全意的存在感 - 专注 - 对他说话 - 眼神接触

Title: #self

聽對方的故事 表達你的觀點與感受 - “這件事 我還沒定論，想先聽你怎麼看 “ - “目前我比較請向/比較在意的是“

共同探索 - “我們這件事的方式好像不一樣， 我想說我的， 也想聽你的”

- 你負責把重要的話說清楚； 對方開不開，接不接，是他們的份

假設 帶頭 = 付全隊責任 - 你可以負責 你的看法，感受，底線 + 不必負責“對方的情緒與選擇”

-  邀請一起想，一起分責
    +   不必負責 “整件事的最終成敗”

-  拒絕 ”聽完等於接單“
    +    不必負責 “永遠懂別人，永遠 不露自己” 的好人劇本

How - “我聽到你在意的是...； 我這邊還沒想透答案， 但目前對我重要的是 ...; 我們可以一起想，我不想一個人決定/執行整件事 - 你覺得哪一塊該你，哪一塊可以一起？“

父親的負責 - 全扛/累得半死 - 但我的是

團隊結果 = 我們各貢獻的總和 - 我的失敗 = 我事先認領的那部分

領導／被跟隨的現實較準的版本是 - 人跟的是可預期的分責、清楚的界線、搞砸後還能回看貢獻 + 人跟的是可預期

- 很少是「永遠第一、從不輸給別人」。你若把「必須優於他人」當跟隨條件，比較會永遠綁架你。
