发现自己很习惯听从对方的言辞 而不是 兜自己，撑自己 - 潜意识 将“顺从” 等同于 “建立连接” 或 “安全感” 进而变成单方面的配合，而不是真正的连接

- “撑自己”  是 对自己所呈现的状态负责
    +   不需要 通过对方的认可才可能存在
    +   设定心理围栏

-   从 “关系消费者” 转变为 “关系创造者”
    +   习惯于 “听从”， 是因为你把自己定位成了这段关系的 “观察员” 和 “维护者”

    +    需要开始把自己定位成 “体验者”
          -  告诉自己。“我是来和他们交换能量的， 而不是来申请他们的认可的”
          -  ” 这不是你最爱的吗？“

    +     那些优秀的人 其实更欣赏那种有定力，有自我观点的人
           - “这是一个很有趣的视角， 我个人的看法是  …”

社交连接 - 健康的人际关系， 是 “能量交换”的协作制， 不是“服务与被服务“ + 给出偏好 - 减少对方的 “猜测成本”： 替对方省心 - 关系的 “共同建设”： 参与，才是对对方劳动的最大尊重 - 个人边界： 如果没有偏好，就会变成一个 “模糊面孔”

   + 分担压力 
         - 主动承担一个小任务

         -  变成 “我们在处理这件事”

-   通过 ”提议 + 兜底“ 逻辑

-   给出信息 + 表达尊重 （如果有别的想法，我也ok， 听大家的）

自己的要么参与要么不参与

参与的定义 + 我参与，是因为我想和这个人建立连结， 而不是成为他的解决方案 + 参与动机 从“解决问题” 转换为 “建立连结”， 自己就不再需要“承担责任”来证明你的价值

      +.  你不需要在人格上覺得自己低人一等，但在「姿態上」，你可以給予他階級上的尊重

关系中的 “灰度空间” - 中度参与缓冲区 + 陪伴着 - 只需要 “在场”， 不需要参与决策或解决问题

      +   咨询者 - 提供建议但不介入执行 
             -  明确告诉对方： 这是我的观点， 但我尊重你的决定

      +   伙伴 
             -    只保留给最核心的关系 （伴侣，导师）

從「分析」轉為「參與」 + 不要把自己變成解決問題的外部機器，而是變成「陪他一起解決問題的戰友」。將「你應該怎樣」變成「我們可以怎樣」。 + 不需要成為對方的「救世主」，你只需要做一個「可靠的同伴」 + 賦予對方決策權：對方遇到問題，不要說「我幫你解決」，而是說「如果你想處理這件事，我可以陪你一起看數據，或者幫你分析利弊，但最後怎麼走，還是由你決定」。

      + 坦白你的「能量額度」
             - 我很乐意听你说， 但这件事的决定权还是在你身上

当面对‘上位者思维“时 + 将尊重 从 ”客观“ 提升为 ”不可侵犯的专业感“ - 客观语言必须带上“边界感” - 过于客观， 你把自己的立场也变成了一个“选项”， 对方就会觉得可以来“复写”你的立场 - 调整策略： 强化你的“领域所有权” + “ 如果有不同建议，请基于数据提出，我们再来讨论”

     +    及时且温和的反击
             -   当对方打断你或否定你时
                 +  “请让我讲完，这对团队沟通很重要”， 你只是在强调规则

     +   当对方踩界，收回“平时”   禮遇，改用「專業對抗」模式。

你追求的是一種「對等、尊重且理性」的相處模式; 希望透過「客觀平視」，來避免關係中出現權力不對等（上下級關係）

平视 不等于 客观 - 你認為平視是「雙方都保持理性、就事論事」；但在大多數人的情感維度裡，平視的定義是「情感上的對齊」。

- 訊號錯誤原因： 你用「資訊層」去覆蓋了「情緒層」

客觀語言的最大特點是「無情緒波動」 - 在人際互動中，它會傳遞出一種**「這件事不重要，你太情緒化了」的潛台詞

 - 當對方遇到困難，想要的是「共鳴」；你給出客觀分析，對方接收到的卻是「否定」

 - 矛盾點： 你想避免上下關係，但你的客觀分析反而建立了一種「我比你理性，所以我來教你正確做法」的權威感。

需要從「客觀的平視」轉換為「主觀的同步」 - 練習「情緒先於邏輯

 -  從「分析」轉為「參與」
      +  不要把自己變成解決問題的外部機器，而是變成「陪他一起解決問題的戰友」。將「你應該怎樣」變成「我們可以怎樣」。
      +  不需要成為對方的「救世主」，你只需要做一個「可靠的同伴」
      +   賦予對方決策權：對方遇到問題，不要說「我幫你解決」，而是說「如果你想處理這件事，我可以陪你一起看數據，或者幫你分析利弊，但最後怎麼走，還是由你決定」。

      + 坦白你的「能量額度」

 - 展現你的脆弱
      + 一個總是客觀、理性的人，在他人眼中是「無懈可擊」的。但**「連結」發生在缺口處**。偶爾展示你的困惑、你的疲累
