直接面谈 而不是 中间人 -

忍耐 代替 了 沟通 - 多一事不如少一事

Title: #self

資訊不對稱的失衡 - 你在明處， 對方在暗處； 對方 對妳進行 審視或評估 - 留在這個局裡， 只會不斷消耗你的情緒價值， 並將主動權拱手相讓

情感邊界的模糊 - 情感問題家族化， 捲入了對方家庭的社交審查體系中，失去了個人尊嚴與空間

沈沒成本謬誤 - 投入了感情與精力， 讓你感到不甘心或難以抽身

經驗教訓 - 情感界線 過於模糊與包容 + 習慣用“ 既來之則安之”的心態去消化突發狀況， 這雖然展現了你的隨和與大氣，卻也無形中允許了 對方不斷試探，模糊你的主動權

     +    習慣用時間和耐心去包容不完美的過程，但這也讓你付出了被情緒勒索和隱私試探的代價

     +    正確的做法是 “人走茶涼”：  人離開， 茶自然涼， 不必留戀

-  你事一個重感情，講情義， 但也容易被 “侷限”的人
     +    說明你做決定時， 常常會顧及既有的社交慣性，或者對 “徹底決裂” 有一種心裡上的抗拒
     +    太能 忍耐環境，  無形中消耗了你的心智， 讓你無法將精力聚焦在更有價值的事情上

-   警惕第三方介入的權力動態
     +    對於無法直接，坦誠溝通的對象， 越早止損越好
     +     這反應對方 在人際交往中 帶有很強的 防備心或試探心裡
  • 認清 “止損”的定義

高韌性與長期主義，留給更值得的人和目標 - 對於消耗你能量的人， 事，局， 果斷執行“斷捨離”， 把你的長期主義 與 高韌性， 留給更值得的人和目標

-  把資源與精力重新錨定在你自己身上

分清 “值得” 與 “消耗” - 把 包容 與 高韌性 留給那些 懂得 尊重你邊界， 雙向奔赴的人 對於 那些 試探， 功利， 果斷刪除

自我定價權 - 你的價值來與你的專業能力， 你的資產管理能力 以及你的真實品格； 絕對不要在任何一段關係或階層落差中把自己放在 審視席上

- 你的稀缺資源： 注意力和時間

-  深耕健康的社群與真正的連結
    +  多和那些 真誠， 雙向奔赴，交往純粹的人在一起
  • 有些背景看似優越，背後可能伴隨著極高的防備心，功利性與複雜的家庭敢於 + 自己喜歡的女生： 善良， 開放， 樂觀， 大方

帶有鋒芒的高價值好人 - 好人 的定義 是 “ 把善良留給懂得珍惜的人， 把冷漠與果斷留給消耗你的人” + 用“忍耐” 代替 “溝通”： 面對不尊重或不合理的對待時，傾向於自我消化，認為 ”多一事不如少一事“ + 習慣壓抑自己的不舒服去迎合他人， 不懂說”不“

-  有界線的善良：  善意是 有原則，有門檻的。 當別人踩過紅線或不尊重他們時， 他們能立刻察覺並強勢反擊或轉身離開

-  懂得把寶貴的時間和心力， 留給那些 能夠 “雙向奔赴”的優質關係

-   言行一致的底線 integrity:   做人光明磊落，但也絕不當無條件的冤大頭
