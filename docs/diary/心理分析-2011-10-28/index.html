心理分析

2011-10-28
#diary

2011-10-28-diary

  1. 恐惧失败，追求完美 拖延除了作为一种自我保护的心理策略之外，它也是源于你对生活的一些顽固信念,比如 我必须要做到完美；没有什么是我无法做到的； 如果这一次我做得很好，那么我每次都应该做得很好； 如果我展现真实的自己，人们不会喜欢我的； 认为必须做到完美，宁愿拖延也不愿意去努力做事，不愿意冒风险被人评判你的失败； 害怕有人会发现他们的这些缺陷； 太在乎别人的评判 ======> 多数拖延着并不明白，在他们经常把事情搞得一团糟时，怎么还可能被看成是完美主义 者。喜欢拖延的完美主义者有一些他们钟爱的信念： 平庸招致轻蔑。 贬低平常和常规的表现，以轻蔑的眼光来看待它。因为在人类的生活中错误和差池在所难免，所以那些不能忍受平常表现的人往往通过拖延来安慰自己。 我无法忍受失去。 很多完美主义者憎恨在竞争中失败，所以他们尽量避免参与到跟别人直接竞争的活动中，表面上对竞争不感兴趣掩盖了他们的真实感觉:竞争是危险的。因为没有胜出意味着他失败了，而失败意味着他一无用处。 *要么全部要么没有 =====>成长心态。是指能力是可以发展的；通过努力工作，你可以随着时间推移而变得更聪明，更优秀。你没有必要立刻擅长某些事情，事实上，做一些不擅长的事情反而更有趣，因为通过做这样的事情，你可以拓展自己并从中学习。失败可能会让你伤心和失望，但是成败并不决定一个人本身的好坏。 它可以拆解自我价值感等式，表现不仅不能反映你的个人价值，而且它也不再是你关心的重点！ 重要的是你学到了什么，你对什么感到兴奋，你提升了什么，而结果只是一个背景而已。 完美主义者在思考他们所做事情的时候容易绝对化，也经常性的方式思考问题。 当你发现自己陷入完美主义者的心理瘫痪时，想象在那种情况下最糟糕的处境究竟是什么。进而将自己的固定心态转化为成长心态，你或许会以全新的眼光看待不完美：它是你提升自己，学习新知识的一个推动力，而非致命打击。 ======>她把成功定义为“及时追随目标”，从这个定义来看，不论什么时候，只要我们在做自己想做的事情，就会感到自己是成功的。 “及时追随目标” 会将你渐渐引向其它定义的成功，同时它也可以让你在付出努力的时候能感受到成功。 ======>你害怕成功吗？ 当你假定获得成功意味着伤害他人，你就在成功与侵犯之间划上等号。 他们或许比我们想象的更加坚强，大方。也许我们扭曲和误会了周围的现实，让我们以为我们的成就不可避免地会伤害的别人。 ======>别人的评判不也是对自己的问题的指导吗？也是促使自己的进步呀
  2. 个人独立性问题。 自小有些娇生惯养，进而有些养成了自我，让别人服从于自己的想法或者习惯，也养成了习惯于按照自己的想法来做事，确保自己不被人控制，为了赢得个人的权利感和主导自己生活的权利，牺牲掉一些重要的事项。 当对独立性的需要成为一个人生活中压倒性倾向时，做抉择的过程会变得困难。当投身于某种关系时，意味着把自己的利益和偏好暴露给全世界看，一旦做出这样的决定，就不能再完全控制局面。对害怕在征战中败下来的拖延着而言，把自己所想所感暴露给别人看会让他们感到自己极为脆弱相比，他们关注的不是一旦暴露就有人来评判他，而是他们的权利会被解除，他们的弱点会被追究。而秘密战斗似乎要安全多了； 争战的根源，你怎么会开始就把这个世界看成是一个战场（从小受到的教育，比如排名文化） =====>当你产生抵制冲动时，可以这样问自己 ”我这样的反应针对的是什么？“ 有些时候，你的抵制情绪来自于你自身的恐惧，而非现实状况。 一个请求不一定意味着控制；一个规则并不必然是一个无法逃脱的牢房，而与人合作也可能是一件令人开心的事情。
  3. 心理舒适区：对亲近与疏远的恐惧 正式因为自小独立惯了，如果关系太近会让人不舒服。 比如害怕要一直维护某种关系的精力，责任和时间,拖延始终是维护心理舒适边界的一种方式 =====> 但是这样不能解决人际关系中根本的问题；任何人际关系中都涉及边界和亲密之间的关系问题，你必须面对并处理好这个问题。你可以将此看成一次让心灵获得成长的机会。无论作为一个个体还是一个伴侣，解决彼此分歧可以看成是你不断学习和拓展自己的一个途径。 拖延或许可以将其他人保持在你需要的人际距离上，但是它阻碍了你的成长。一个良好的关系需要在依赖和独立间取得平衡。
  4. 执行功能障碍 不专注： ======>找到一个目标，然后将它分解成几个小的步骤，跨出小小的第一步，学习怎样记录时间以及如何优化周围环境使之有利于成功的方向推进。 找一个友善且具有优秀执行能力的人跟你一个小组。 ======>抑制自己即使反映； 当你想起将来某些重要的事情时，当你明白现在的所做所为与将来的结果紧密相关时，你就能抑制住自己满足当下欲望的冲动。我们才能跨过一个难关，延迟某些满足。 个人成长中的一个使命就是要发展出对你自己能力的合理认知，并接受自己的局限性，同时又能维护一个积极的自我价值感。过度赞扬会让孩子产生一种不现实的全能感----“我可以做任何事情！” 因为父母不去帮助孩子容忍失败和接受现实。 5.要将时间花在那些能够对你坦诚相待，一起欢笑，相互信任，在困难的时候可以依靠的朋友
  5. 从拖延信条中解放出来 ×××××××万事无完美 ×××××××努力尝试是一件好事，而不是愚蠢或软弱的表现 ×××××××失败并不危险。失败是正常的，这是生活的组成部分 ×××××××真正的失败是不敢去经历 ×××××××每个人都有局限，包括我自己 ×××××××如果那时一件值得去做的事情，那么为它犯错误也是值得的 ×××××××挑战有助于我的成长 ×××××××我有成功的权利，我也能应对别人对此的反应 ×××××××如果这次没做好，下一次我还有机会 ×××××××遵守别人的规矩去做事并不意味着我一点权利都没有 ×××××××当我展现出真实的自我，真正喜欢我的人就会跟我坦诚相对 ×××××××答案很多，但我需要找到最符合我感觉的答案
