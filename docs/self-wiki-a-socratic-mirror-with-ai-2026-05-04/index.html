Self-Wiki: a Socratic Mirror with AI

2026-05-04
#self #important #proj

about 'Self-Wiki'

"Know thyself" is so hard, while most of time we rely on feedbacks around coachers or friends. Now we can use an AI agent for it, based on personal entries. By moving from a "Knowledge Queries" to a "Socratic Mirror", the agent acts as a mirror, reflecting and expanding our thought to foster self-awareness, emotional regulaton, and deeper cognitive engagement.

Unlike traditional AI that provides answers, the Socratic Mirror, as discussed in Psychology Today, is designed to understand ones own limitations, unconscious, character, motivations, and insights.

The agent incrementally builds and maintains a persistent and compounding wiki automatically. When one adds any new source even each query, the agent will integrates these into the existing wiki so that a structured picture of oneself is given over time. An evolving 'Self-Wiki' by the agent then could used be for psychological integration.

The 'Self-Wiki' also can be on coaching and education service.

Project structure

The structure is as follows:

self-wiki/
├── raw/ (input dump)
├── wiki/ (AI-organized knowledge base)
├── outputs/ (AI-generated answers)
└── AGENTS.md (operating instructions for the AI)

See dev.self-wiki repo for more details.
